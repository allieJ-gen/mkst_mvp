# MKST NewB Survey - 앱스스크립트 프로젝트

## 프로젝트 개요
맥북에서 개발한 앱스스크립트 프로젝트를 맥미니에서 연동 작업하기 위한 저장소입니다.

## 파일 구조
```
mkst_newb-survey/
├── README.md
├── scripts/          # 앱스스크립트 파일들
├── resources/        # 리소스 파일들
└── docs/            # 문서 및 가이드
```

## 앱스스크립트 연동 방법
1. 맥북에서 앱스스크립트 코드 복사
2. 맥미니에서 해당 파일에 붙여넣기
3. 필요한 경우 경로 및 설정 조정

## 개발 환경
- macOS (맥미니)
- 앱스스크립트
- 필요한 경우 추가 도구 설치
